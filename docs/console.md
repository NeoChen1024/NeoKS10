# Operator console commands

Generated by `neoks10 help --markdown` from `emu/neoks10/src/cmd.rs`. Do not edit. The design is in `docs/emulator.md`, "Operator console".

| Command | Function | Needs a halt |
|---|---|---|
| `help` | List the commands | no |
| `cty` | Return to the CTY (an empty line does the same) | no |
| `quit` | End the program | no |
| `cpu show` | Show the processor state | no |
| `cpu halt` | Stop the processor (8080 HA) | no |
| `cpu continue` | Continue the processor (8080 CO) | no |
| `cpu step [N]` | Do N instructions (8080 SI) | yes |
| `cpu start ADDR` | Start at an address (8080 ST) | yes |
| `boot disk [UNIT]` | Boot from a disk unit (8080 BT) | no |
| `boot tape [UNIT]` | Boot from a tape transport (8080 MT) | no |
| `disk UNIT attach FILE [--ro]` | Attach a disk image to a unit | no |
| `disk UNIT detach` | Detach the image of a disk unit | no |
| `tape UNIT mount FILE [--ro]` | Mount a tape image at the load point | no |
| `tape UNIT unmount` | Remove the tape of a transport | no |
| `mem examine ADDR[..ADDR]` | Show memory words (8080 EM) | no |
| `mem deposit ADDR WORD` | Write a memory word (8080 DM) | yes |
| `cty send TEXT` | Type text on the CTY (\r, \n, \e, \xHH) | no |
| `send TEXT` | Type text on the CTY (as cty send) | no |
| `cty read [--from N]` | The CTY output from byte N | no |
| `expect TEXT [--steps N]` | Wait for text in the CTY output, at most N instructions | no |
| `show devices` | Show the units and their images | no |
| `record mark TEXT` | Write a mark into the record file | no |
| `script run FILE` | Run a script file; the guest goes on | no |
| `script stop` | Stop the running script | no |
| `script show` | Show the step of the running script | no |

ADDR is octal, with an optional space: `phys:` (the default), `exec:` or `user:`. WORD is octal or `LH,,RH`. UNIT is 0 to 7. TEXT is one word, or text in double quotes.
